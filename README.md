# Code Panium downloads

This repository distributes published companion app installers, supported board firmware and update metadata.

The product source code is maintained privately. This repository contains no companion or firmware source code.

## Downloads

Verified builds will appear under [Releases](https://github.com/manfye/codepanium-releases/releases). There are currently no published releases. Do not use unrelated builds as firmware updates.

Future companion releases will offer update checks inside the app. Board firmware installation requires the supported hardware, a USB connection and explicit user confirmation. Availability will be stated per operating system and board revision.

Update files will be authenticated before installation. Installation availability and compatibility must be checked in the app; this repository alone does not establish compatibility with a particular device.

## Distribution policy

Only intentionally published release files and public update metadata belong here. No private settings, logs, backup images, account information, credentials, signing keys or development snapshots may be uploaded.

Code Panium is a provisional product name. Downloading a binary does not grant a license to redistribute proprietary software or third-party assets; release-specific license notices apply.
